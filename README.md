# 🚴 Pulse Patterns

Like a heartbeat, Boston's bike traffic rises and falls through the day.
An interactive map of 260,000+ BlueBikes rides (March 2024) across Boston and Cambridge.

**Live site:** https://sadhanapt36.github.io/pedal-pulse/

- Station circles sized by total traffic (square-root scale)
- Colored by departures vs. arrivals
- Time-of-day slider to watch commute patterns shift

Built with D3.js and Mapbox GL JS for DSC 106 (Lab 7).
